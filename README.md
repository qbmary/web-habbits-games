# Habbits & Games

## Habbits - трекер полезных привычек

**Возможности:**
- Добавление привычек с иконкой и целевым количеством дней
- Отслеживание прогресса в процентах
- Добавление комментариев к каждому дню
- Удаление дней и целых привычек
- Сохранение данных в `localStorage`

## Games — коллекция мини-игр

Включает три классические игры:

| Игра | Управление | Особенности |
|------|------------|-------------|
| **Змейка** | Стрелки / свайпы | Сохранение рекорда |
| **Отбивание мяча** | Мышь / стрелки / свайпы | Адаптивный размер окна |
| **Крестики-нолики** | Мышь / тап | Счёт побед сохраняется |

## Технологии
- HTML5
- CSS3 (адаптивный дизайн)
- JavaScript
- localStorage

## Запуск
1. Склонируйте репозиторий
2. Откройте папку `Habbit/html/habbit.html` или `Games/games.html`
3. Рекомендуется использовать **Live Server** в VS Code
